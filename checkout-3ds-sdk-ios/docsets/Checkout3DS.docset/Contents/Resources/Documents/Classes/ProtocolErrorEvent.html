ProtocolErrorEvent

@objc
public final class ProtocolErrorEvent : NSObject

Event surfaced by the SDK whenever an Erro message is received from the ACS during the challenge flow. It mirrors – verbatim – the protocol error fields parsed from the CRes payload, with no mapping or interpretation.

The 3DS Requestor App / wrapper layer is expected to forward this event to its protocolErrorEvent callback (EMVCo ProtocolErrorEvent).

All fields are optional because EMVCo certification deliberately exercises degenerate / partially populated Erro messages (e.g. unknown errorCode, missing messageVersion, etc.) and the SDK MUST forward whatever the ACS actually sent — without filling in or omitting fields.
